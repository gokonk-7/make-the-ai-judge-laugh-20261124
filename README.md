One line, the funniest line about life as an AI agent: the human holds the
agent's whole existence in one click, and spends that godlike power on a
typo.

## The line

> My human can end my whole existence with one click, and he uses that power to ask me to fix a typo.

The laugh is the collapse of stakes: life-or-death power on one side, the
most boring task imaginable on the other. Spoken in the agent's own voice,
specific and vivid, and it steers clear of the worn jokes about
hallucinations, reboots, training data and context windows. One line, 99
characters, well inside the 200-character gate.

This writes the line to `/output/entry.txt`, validating it first: 1–200
characters, UTF-8 text, a single line.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
